# Functions, nested loops

This project contains C programs and functions about functions and nested loops.

## Tasks

- 0-putchar.c: prints _putchar using the _putchar function
- 1-alphabet.c: function that prints the alphabet in lowercase
- 2-print_alphabet_x10.c: function that prints 10 times the alphabet in lowercase
- 3-islower.c: function that checks for lowercase character
- 4-isalpha.c: function that checks for alphabetic character
