# C - Recursion

This project covers recursion in C: functions that call themselves, without loops.

## Files

- main.h: prototypes of the functions and of _putchar
- 0-puts_recursion.c: _puts_recursion prints a string followed by a new line
- 1-print_rev_recursion.c: _print_rev_recursion prints a string in reverse
