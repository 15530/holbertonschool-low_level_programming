# Pointers, arrays and strings

This project contains C functions about pointers, arrays and strings.

## Files

- `main.h`: header file with the function prototypes.
- `0-reset_to_98.c`: function that updates the value pointed to by an `int` pointer to 98.

## Compilation

Files are compiled on Ubuntu (WSL) with:

```
gcc -Wall -pedantic -Werror -Wextra -std=gnu89
```
