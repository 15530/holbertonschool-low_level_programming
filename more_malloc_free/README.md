# More malloc and free

This project contains C functions that use dynamic memory allocation.

## Files

- `main.h`: header file with the function prototypes.
- `0-malloc_checked.c`: function that allocates memory using malloc and exits with status 98 on failure.

## Compilation

Files are compiled on Ubuntu with:
- `1-string_nconcat.c`: function that concatenates two strings, using at most n bytes of the second.
- `2-calloc.c`: function that allocates memory for an array and sets it to zero.
gcc -Wall -pedantic -Werror -Wextra -std=gnu89
