# Simple Calculator

A simple command-line calculator written in C.

## Description

The program displays a menu, reads the choice of the user and quits when the choice is 0.

## Compilation

gcc -Wall -Werror -Wextra -pedantic -std=gnu89 calculator.c -o calculator

## Author

Ousmane

## Numbers

The calculator uses decimal numbers (double). Results are printed with %g, so 10 + 25 prints 35 and 10 / 4 prints 2.5. Dividing by zero prints: Error: division by zero
