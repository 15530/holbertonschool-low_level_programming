# Hello World

This project contains C and shell tasks about compiling.

## Tasks

- 1-compiler: compiles a C file without linking
- 2-assembler: generates the assembly code of a C file
- 3-name: compiles a C file and creates an executable named cisfun
- 4-puts.c: C program that prints a sentence using puts
- 5-printf.c: C program that prints a sentence using printf
- 6-size.c: C program that prints the size of various types
